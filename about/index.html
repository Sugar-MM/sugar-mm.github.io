4) Learning I-Land AI 教育 Agent 设计｜AI Agent 开发

项目简介：围绕学生学习过程设计 AI 教育 Agent，用于完成“学习问题理解 -> 知识点定位 -> 学情记忆召回 -> 解题路径规划 -> 个性化讲解 -> 练习题生成”的闭环。学生可以用自然语言描述不会的题、薄弱知识点或学习目标，Agent 根据历史学习记录、错题反馈和知识库内容生成分层讲解与下一步练习建议。

核心架构：

  • 学生问题输入 -> FastAPI Agent 服务 -> LangGraph 状态图编排 -> Qdrant 知识库 / 学习记忆检索 -> LLM 推理生成 -> 校验节点 -> 结构化学习建议输出。

技术栈：

  • Python / FastAPI / LangGraph / Qdrant / OpenAI API / Pydantic
  • MySQL / WebSocket / Docker

技术亮点：

  • Agent 工作流编排：基于 LangGraph 拆分意图识别、知识检索、学情分析、讲解生成、练习生成、结果校验等节点，避免单次 Prompt 直接生成导致结果不稳定。
  • 学习记忆系统：将学生错题、已掌握知识点、最近练习反馈写入 Qdrant，下一次答疑时召回相似学习记录，生成更贴近个人情况的讲解。
  • RAG 知识增强：按年级、章节、知识点、题型构建向量检索上下文，让 Agent 回答时能结合课程知识库，而不是只依赖模型自由发挥。
  • 结构化输出：通过 Pydantic 约束返回学习建议、知识点标签、解题步骤、推荐练习和风险提示，方便前端直接渲染成学习卡片。
  • 工具节点设计：把难度评估、知识点匹配、练习推荐、学习进度更新拆成可复用工具，提升 Agent 输出的可控性和可维护性。
